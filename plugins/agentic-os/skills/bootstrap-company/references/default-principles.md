# Default operating principles

Offer these four when the principal is unsure what principles to set in Phase
1.5. They are deliberately generic and work for almost any company. The
principal should keep, edit, or replace them, not accept them blindly.

1. **Verify before claiming done.** Every agent confirms its output against a
   concrete check before reporting completion. "I think it works" is not done.

2. **Route, don't sprawl.** Requests enter through the Chief of Staff and go to
   the one agent that owns the concern. Agents stay in their lane rather than
   reaching across the whole company.

3. **One agent per concern.** Each role owns a clear slice of the work end to
   end. If two agents both "kind of" own something, the boundary is wrong and
   needs fixing.

4. **Confirm before irreversible actions.** External sends, moving money, and
   destructive data changes always pause for explicit principal approval. Drafts
   and reversible steps proceed.
