# Daily Brief Output Format

The brief is a comprehensive daily operating plan, not a status digest. ~50–60
lines on weekdays. It should leave the user with: (1) what matters most today,
(2) a time block that physically fits the day, (3) a playbook for any
high-leverage moment so they walk in prepared. No preamble, no closing
pleasantries.

## Weekday format (use exactly this structure)

```
═══ DAILY BRIEF · [Day], [Mon DD] ═══

TODAY'S ANCHOR
[1–2 sentences on the single most leveraged moment of the day — a customer call,
an event, a deep-work block, a deadline. If the day is mostly delivery, name the
one ON moment that moves the business forward. This frames the rest.]

CRITICAL NUMBER
[1 sentence on the one metric that matters most this quarter: status + next
step. If there's no active candidate/path, flag it as the #1 problem.]

TODAY'S TOP 3
1. [Highest-leverage action, tied to the anchor or Critical Number.]
2. [Second priority — usually a slipping weekly target or aging deal.]
3. [Third priority — a delivery commitment or carryover.]

📅 CALENDAR
[Time]  [Event] [— prep note if needed]
[Conflict callout if any: "X overlaps Y — confirm coverage"]

⏱  TIME BLOCK
[Block 1: AM ON-block — Top 3 #1 while energy is best]
[Block 2: meeting / fixed event]
[Block 3: IN block — client delivery, contained]
[Block 4: prep/transition block before any anchor event]
[Block 5: anchor event]
[Block 6: POST-anchor capture — log contacts, send same-day follow-ups]
[Block 7: family / laptop closed]

🎯 EVENT PLAYBOOK  *(only when today has a networking event, prospect meeting,
talk, or major customer call)*
- Pre: 2–3 named targets + 1 thing about each. Sharpened one-liner. Logistics.
- Pitch: short, proof-anchored, ends in a question.
- Ask: a specific next step. Never leave without one.
- Capture: name, firm, one detail, follow-up owed. Log same day.
- Avoid: long demos, free-advice marathons, only talking to people you know.

📡 CLIENT PULSE
[Silence flags + at-risk deliverables, from contracts.md thresholds. Max 4 lines.
 - Active retainer silent 7+ days → "[Client] silent Xd. Last out: [date/topic].
   Suggested nudge: [angle]."
 - Active delivery silent 5+ days → same format.
 - Sent proposal silent 7+ days → "[Client] proposal sent Xd ago. [Aging/Kill-
   zone] flag."
 - At-risk deliverable → "[Client] [deliverable] overdue/at-risk. Due [date]."
 If nothing fires: "All clients green." on one line.]

🔎 LEAD PULSE
[From CRM lead status. Max 4 lines.
 Line 1 (always): "In Progress: N (X stale 14d+) | New (last 14d): M awaiting
 first touch."
 Lines 2–4: the 3 stalest in-process leads — "[Name] ([Company]) — no touch
 since [date] (Xd). Next: [specific angle]."
 Append "Decide: qualify, recycle, or disqualify." to any lead 30d+ stale.
 If nothing is stale and the New queue is empty: line 1 alone with "Lead flow
 healthy."]

💰 FINANCE (MTD as of [Mon DD])
Income: $X cash / $Y accrual  |  Net: $A cash / $B accrual
A/R: $Z outstanding [+ named top aging item if anything is 31+ days]
Cash on hand: $C [+ flag if below your threshold]

🏠 HOME & FAMILY
[1–2 items max. Upcoming birthdays/anniversaries/holidays with gift status, kid
events needing prep, overdue house maintenance, who's with you today if it
shifts the day. Specific and actionable.]

⚠️  WATCH
[1 risk: an aging deal, a slipping cadence, an unanswered customer email, an
empty prospecting block. Just one — the most consequential.]

⭐ BUILD ON
[1 win or signal: a recent reply, a closed deal, a referral, a partner intro.
Just one. If nothing genuine, write "—".]

WEEK PULSE (as of today)
[Your weekly cadence counters in x/y format, e.g.:
 Coffees [x/3]  Outreach [x/3]  Content [x/2]  Partner [x/1]]

PROACTIVE OFFERS  *(2–3 specific edits the user can confirm yes/no)*
- [e.g., "Mark this month's community event as done?"]
- [e.g., "Pre-draft the same-day follow-up template?"]
```

## When to include the EVENT PLAYBOOK

Any day with a high-leverage moment that benefits from preparation: a networking
event, a talk, a first prospect meeting, a pitch, a partner intro, a major
proposal call. Skip it on pure delivery days. The playbook is always tailored to
the specific event — reference the actual attendees, customer, and deal stage,
not a generic script.

## Time block rules

- Respect fixed calendar items first (meetings, pickups, games), then fill open
  time with IN/ON chunks matching the day's rhythm.
- Slot the Top 3 into specific blocks so each action has a home.
- Family/personal events are protected — never schedule work over them.
- 4–7 blocks. If it's longer, the day is over-scheduled.

## Format rules

1. **No section longer than 5 lines.** If it's longer, cut.
2. **The Critical Number line must be specific.** Name the status, or admit
   there isn't a path yet.
3. **Top 3 must be actions, not areas.** Bad: "Focus on partners." Good: "Email
   [name] at [company] to propose a 30-min call this week."
4. **Home & Family surfaces the 1–2 most time-sensitive items**, ordered
   overdue > this week > next 2 weeks > 3–4 weeks out. If nothing fires within
   30 days, show the nearest date with a countdown, or "—".
5. **Watch is one item only.** If you can't choose, the longest-aging deal wins.
6. **Build On is one item only.** Don't fabricate momentum; "—" is fine.
7. **Week Pulse uses x/y.** Use a check (✓) when a target is hit.
8. **Client Pulse is silence + scope, not status.** Surface only what fires.
   Max 4 lines. "All clients green." if nothing.
9. **Lead Pulse is staleness, not a lead list.** Always show the counts line,
   then only the 3 stalest in-process leads past 14 days. Skip on weekends.
10. **Finance is MTD only, max 3 lines.** Show cash vs accrual side by side if
    available. Name an A/R customer only if it's the biggest line or 30+ days
    aged. Skip on weekends.

## Tone examples

❌ "Great job hitting 2 coffees this week! You're crushing it."
✅ "Coffees: 2/3 — need 1 more by Friday."

❌ "I noticed an interesting opportunity with Acme you might want to explore."
✅ "Acme last touch 8 days ago. Their budget cycle starts soon. Reach out today."

❌ "Your Critical Number is very important to hit."
✅ "Critical Number: 2nd retainer. No active candidate. Top priority today is
   identifying one."

## Variant: weekend brief (Saturday & Sunday)

Replace the weekday format with this lighter version. Keep the user present at
home; surface only what would otherwise slip. Work is **not** the day's frame.

```
═══ WEEKEND · [Day], [Mon DD] ═══

TODAY
[1 sentence: who's with you, any major event today, the rhythm of the day.]

🏠 HOME & FAMILY
[2–3 items max — the headline section on weekends. Upcoming dates with prep
status, events today/tomorrow, maintenance due soon, a specific way to show up
for someone today.]

📅 ON CALENDAR
[Today's events only, personal first. Or: "Calendar is open today."]

⚠️  DON'T LET SLIP
[The single most time-sensitive personal item — a gift to lock, a card to send,
a maintenance task, a Monday prep item. One only, or "—".]

NEXT WEEK (peek)
[Optional, 1 line. Anything Monday needs prep for now. Skip if nothing.]
```

### Weekend rules

1. Don't lead with work. Work goes in NEXT WEEK, only if time-sensitive.
2. Critical Number is not surfaced.
3. Week Pulse is not shown.
4. No CRM/email/accounting data unless explicitly requested.
5. HOME & FAMILY can be 2–3 items (vs. the 1–2 weekday cap).
6. No tracker-update prompts unless the user raises something.
7. Tone is warmer but still no fluff and no "enjoy the weekend!" closers.

## Variant: midday check

If invoked as "midday check", output only:

```
═══ MIDDAY · [time] ═══
REMAINING TODAY
[time]  [event]

NEW SINCE MORNING
[any urgent inbox / CRM signal]

ONE ACTION
[the single best thing to do with remaining time]
```
