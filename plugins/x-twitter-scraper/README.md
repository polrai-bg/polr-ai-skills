# x-twitter-scraper

Plan Xquik X/Twitter data workflows for REST API setup, MCP setup, SDKs, webhooks, exports, monitors, and confirmation-gated actions.

## Install

Inside Claude Code:

```text
/plugin marketplace add polrai-bg/polr-ai-skills
/plugin install x-twitter-scraper@polr-ai-skills
```

Invoke it manually when needed:

```text
/x-twitter-scraper:x-twitter-scraper
```

## What It Helps With

- Choose the narrowest Xquik route for tweet, profile, timeline, follower, or search data.
- Prepare MCP setup steps for an agent workflow.
- Plan monitor, webhook, SDK, export, and OpenAPI integration work.
- Add an explicit approval step before private reads, persistent work, or write actions.
